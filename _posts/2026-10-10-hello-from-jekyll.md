This site is built with Jekyll and served from GitHub Pages. Every post is a Markdown file in the `_posts` folder, named with the date and a short title:

```
_posts/2026-10-10-hello-from-jekyll.md
```

## How a post is put together

The block of settings between the `---` lines at the top is called front matter. The two you need are `layout: post` and a `title`. The first paragraph of the post becomes the excerpt shown on the home page.

## Publishing

Commit the file to the `main` branch and GitHub rebuilds the site, usually within a minute or two.
